# Dra. Jamylle Mayra

Site editorial em Next.js, React e TypeScript, personalizado a partir do template Premium Vendas V4. Um único projeto, pronto para importar no GitHub e na Vercel. Não usa Sites, banco de dados, variáveis secretas ou imagem OG.

## Executar

Requisito: Node.js 20.9 ou superior e npm.

```sh
npm ci
npm run dev
```

Abra http://127.0.0.1:3000.

## Verificar e gerar produção

```sh
npm run typecheck
npm run build
npm start
```

## Vercel

Importe este repositório, selecione o framework Next.js e mantenha a raiz do repositório. Instalação: `npm ci`. Build: `npm run build`. Saída e demais opções: padrões do Next.js. Nenhuma variável de ambiente é obrigatória.

## Conteúdo e identidade

- Dados e contatos: `data/site.ts`.
- Cores compartilhadas: `app/jamylle.css`.
- Fotografias reais originais: `public/images/jamylle-*.png` e `public/images/registro-*.jpg`.
- Fontes locais com licenças: `public/fonts`.
- Favicon vetorial JM: `app/icon.svg`.

As fotos fornecidas são usadas sem retoque, alteração de pele, rosto ou resultados. Dois registros contêm comparativos lado a lado; quatro são fotos únicas. O visualizador preserva essa distinção e a orientação original. As informações profissionais foram transcritas dos anexos fornecidos, sem endereço, depoimentos ou qualificações adicionais.

Paleta: grafite `#191817`, carvão `#292522`, marfim `#F5F0EA`, branco quente `#FCFAF7`, taupe `#9A7C69`, champagne `#D9BFA6`, areia `#E7DDD3`, cinza quente `#756B64`. Tons auxiliares: nude `#F0E7DF`, fundo fotográfico `#E9DFDD` e preto para sombras.

Para uma futura imagem OG, sugere-se grafite como fundo, marfim no texto e champagne nos detalhes. Nenhuma imagem OG ou social card é incluída ou gerada por este projeto.
